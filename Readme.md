# Spaceship Titanic - Kaggle Competition

Проект по предсказанию выживания пассажиров космического корабля "Титаник" в рамках соревнования на Kaggle.

## Описание задачи

В этом соревновании необходимо предсказать, какие пассажиры космического корабля "Титаник" были транспортированы в другое измерение во время столкновения с пространственно-временной аномалией. Используя данные о пассажирах, нужно построить модель бинарной классификации.

## Структура проекта

```plaintext
├── space-titanic.ipynb # Основной Jupyter Notebook с EDA, обработкой данных и моделями
├── sub.csv # Файл с предсказаниями для submission на Kaggle
├── test.csv # Тестовые данные (предоставлены Kaggle)
├── train.csv # Тренировочные данные с таргетом (предоставлены Kaggle)
```

## Интересные моменты

1. Параметр Age разделили на несколько Age_group
2. Разделили всех пассажиров на группы в соответствии с номерами их билетов (в условии сказано, что первые 4 цифры - это группа)
3. Некоторые пропущенные значения восстанавливали по значению других человек в группе

## Результаты

Лучшая модель: **GradientBoostingClassifier** с accuracy **0.80079**. Это было около 400 места (из 2212)
